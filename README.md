# Generals Hypersonic website

EA has not endorsed and does not support this product.

Generals Hypersonic is a free, unofficial fan mod for Command & Conquer: Generals - Zero Hour that adds Iran as a
fourth playable faction. Command & Conquer, Generals and Zero Hour are trademarks of Electronic Arts Inc.; this project is
not affiliated with Electronic Arts.

This repository is the static website (https://mxalmousawi.github.io/generals-hypersonic-site/). The mod itself is not
in this repository. See `LICENSE.txt` for the website's licence and credits, and `credits.txt` for font credits.
